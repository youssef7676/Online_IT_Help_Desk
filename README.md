 Project Overview

Online IT Help Desk is a backend system designed to help organizations manage IT support requests efficiently.
Users can create support tickets, and IT staff can manage, track, and resolve issues through a centralized system.

---

 Features

- Create support tickets
- Track ticket status
- Assign tickets to IT support staff
- Manage users
- Update and resolve issues
- Authentication and authorization

---

 Architecture

This project follows Clean Architecture principles to keep the system scalable and maintainable.

Project Structure

- IT_Help_Desk.API → API layer (Controllers & Endpoints)
- IT_Help_Desk.Application → Business logic
- IT_Help_Desk.Domain → Entities and core models
- IT_Help_Desk.Infrastructure → Database and external services

---

 Technologies Used

- .NET
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- Clean Architecture
